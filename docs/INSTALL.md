# Install / نصب

## One-liner

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/OWNER/khaymali/main/install.sh)
```
(Replace `OWNER/khaymali`, or export `KHAYMALI_REPO=owner/repo`.) The script downloads the release
for your CPU (amd64/arm64), **verifies its SHA-256**, installs `khaymali` + `khaymali-manager`, and opens the menu.
If no release exists it builds from source.

Then run `khaymali-manager`. Recommended order:

| Step | Where | Menu |
|---|---|---|
| 1 | Exit server (abroad) | `1` Setup EXIT → copy **Exit join code** + note the Exit public key |
| 2 | Entry server | `2` Setup ENTRY → paste Exit join code → copy **Entry public key** |
| 3 | Exit server | `8` Manage keys → add the Entry public key |
| 4 | (Bridge mode only) Entry | pick *Bridge* in step 2 → copy **Bridge join code** |
| 5 | (Bridge mode only) Bridge machine | `3` Setup BRIDGE → paste Bridge join code → copy **Bridge public key** |
| 6 | (Bridge mode only) Entry | `8` Manage keys → add the Bridge public key |

Not sure whether you need a Bridge? On the Entry server run `khaymali-manager doctor <exit-ip> 443`
(menu 9). It runs the TCP / path / UDP / DNS checks and prints a Direct-vs-Bridge verdict.

Join codes contain the camouflage secret. Treat them like passwords; do not paste them in public.

## Files
`/etc/khaymali/<role>.conf` (settings) · `/etc/khaymali/<role>.env` (private key, mode 600) ·
`/etc/systemd/system/khaymali-<role>.service` (regenerated by the manager) · logs: `journalctl -u khaymali-<role>`

## More manager features (0.4.0)
`10` port forwards with loop check · `11` edit config (validated, auto-rollback) · `12` opt-in scheduled restart timers ·
`13` kernel tuning / BBR with real revert · `14` Telegram alerts (service down, restart loop, adaptive blackout, boot report) ·
`15` backup / restore of `/etc/khaymali` · `16` disk & log cleanup · `17` update (binary+scripts, or manager script only).

## Non-interactive
`khaymali-manager status|doctor|logs|update|update-manager|backup|restore|tune|tune-revert|tune-status|cleanup|notify-test`. Environment: `KHAYMALI_VERSION=v0.3.0`, `KHAYMALI_BUILD=1`,
`KHAYMALI_BIN=/path/to/khaymali`, `KHAYMALI_NO_MENU=1`.

## Publishing your own copy (for maintainers)
1. Push the repo to GitHub, set `OWNER/khaymali` in `install.sh` and `scripts/khaymali-manager`.
2. `git tag v0.3.0 && git push --tags` → the `release` workflow builds static musl binaries for amd64/arm64 and attaches them with checksums.
3. Users run the one-liner above.

# نصب (فارسی)

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/OWNER/khaymali/main/install.sh)
```
بعد از نصب، دستور `khaymali-manager` منوی مدیریت را باز می‌کند. ترتیب کار:
۱) روی سرور **خارج**: گزینه ۱ (Exit) ← «Join code» و کلید عمومی Exit را بردارید.
۲) روی سرور **ایران**: گزینه ۲ (Entry) ← کد را paste کنید ← کلید عمومی Entry را بردارید.
۳) برگردید روی Exit، گزینه ۸ ← کلید عمومی Entry را اضافه کنید.
۴) اگر Entry به Exit دسترسی ندارد (گزینه ۹ «doctor» را بزنید): در مرحله ۲ حالت Bridge را انتخاب کنید، کد Bridge را روی
ماشین واسط در گزینه ۳ وارد کنید و کلید عمومی Bridge را در Entry (گزینه ۸) اضافه کنید.

نکته: Join code شامل راز استتار است؛ مثل رمز عبور با آن رفتار کنید. منو انگلیسی است چون ترمینال‌ها فارسی راست‌به‌چپ را درست نمایش نمی‌دهند.
