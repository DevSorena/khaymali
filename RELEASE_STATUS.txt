Khaymali Tunnel v0.22.1 - verified build
=======================================
What was actually run (Linux sandbox, 1 CPU core, Rust 1.75 with older pinned crates; the project
toolchain is 1.85, so run the commands below once on your own server before publishing):

  cargo test --release              163 unit tests + 22 security tests: all pass
  tests/eof_e2e.sh                  4/4   stream EOF in both directions, default settings
  tests/pool_e2e.sh                 5/5   multi-Exit pool: balance, drain, standby failover
  tests/autopilot_e2e.sh            5/5   down/recovered detection, history, webhook alerts
  tests/integration.sh              14/14 (includes multi-exit failover)
  tests/khaymali_suite_e2e.sh       pass  carriers, GRE allocator, Spoof+WG, Mesh NAT, live WS+WSS
  tests/manager.sh                  43/43 (6 consecutive runs; a SIGPIPE race in restore was fixed)
  tests/intelligence_cli.sh         pass
  CLI smoke test                    50 subcommand invocations: no panic, no hang

Stress (tests/stress_harsh.sh, 200/250/300 SOCKS clients, 10 hostile profiles, 2 repeats = 15,000
requests per mode):
  shadow  53/60 runs pass, 13,347/15,000 requests ok (89.0%)
  active  54/60 runs pass, 13,463/15,000 requests ok (89.8%)
  Pass in both modes: clean, latency 300ms+-100, loss 10%, loss 25%, early RST 30%, freeze,
  blackhole bursts, hostile mix, per-connection throttle 256 KiB/s (first cold step can be slower).
  Fails in both modes: pmtu_drop_4k (0-1%). The proxy deletes bytes from inside the TCP stream,
  which real TCP never does, and it permanently breaks the encrypted stream. Whether a REAL PMTU
  blackhole is handled has not been verified.
  shadow vs active differ only within noise: this run does not show a benefit from active NLP.

Not verified here (needs a real server): root-only features (netns/tc, GRE/FOU, nft, systemd,
WireGuard, raw-socket spoof), real Telegram delivery (bot and alerts), real Iran<->abroad paths,
tests/chaos.sh, tests/netem.sh, scripts/stress_harsh_300_ab.sh, tests/stress.sh.
