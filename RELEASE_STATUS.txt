Khaymali Tunnel v0.22.7 — Optimized Final Release (2026-11-28)
=====================================================================================
This package merges the v0.22.7 security hardening with professional packaging
improvements from the 0.22.6 readiness pass.

Security (session resume — critical):
  - AttachReq carries resume_token; Exit stores the real token (no more [0u8;32]).
  - authorize_attach verifies HMAC(token, exit_static_pub || session_id || epoch)
    BEFORE the replay ledger is updated (forged proofs cannot burn the victim's epoch).
  - Noise peer + token constant-time match required to resume; empty-peer bypass removed.
  - SessionRegistry::insert refuses overwrite of an existing session_id.
  - ReplayLedger FIFO-evicts oldest proofs instead of clear().

Probe fidelity (camo / fallback):
  - Plain-HTTP probe body is drained up to CRLF-CRLF / 200ms before decoy forward.
  - Decoy ConnectionReset/Aborted is mirrored with SO_LINGER=0 (RST), not only FIN.

Packaging & build optimizations:
  - Professional Cargo.toml with repository, keywords, categories, authors, rust-version.
  - Feature flags: core (default), cluster, spoof, xray, ssh, l3, nlp, autopilot,
    session-resume, experimental/ktunnel, and full meta-feature.
  - Release profile: opt-level=3, LTO=thin, codegen-units=1, panic=abort, strip=symbols.
  - Added thiserror + bytes; signal feature for tokio.
  - CLI helpers extracted into src/cli/ for maintainability.
  - Library docs updated to v0.22.7.

Verified previously:
  cargo test --lib --release (173 unit tests pass; includes forged_attach, resume_frame+token)
  Known intermittent race in live_tcp_session_survives_carrier_kill_and_reattach under
  fast release builds — wait loop present; re-run if network allows.

Deploy note: Entry and Exit must both be v0.22.7+ for mux resume (AttachReq wire format
gained the token field). Direct non-mux streams are unchanged.

Build recommendation:
  cargo build --release --features full
  # or minimal / most secure:
  cargo build --release --no-default-features --features core,session-resume
